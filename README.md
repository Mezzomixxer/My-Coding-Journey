# My C++ Learning Journey

I started learning C++ on **July 18, 2026**, as a complete beginner with no previous programming experience. This repository documents my progress from writing my first programs to taking on more challenging projects as I continue to learn. My goal is not to create perfect code from the beginning, but to build a strong understanding of the language by practicing consistently and learning from my mistakes. Every project in this repository represents a step in that journey and reflects what I knew at the time it was created.

This repository serves as a personal record of my growth as a programmer. Some of the earlier projects may contain inefficient solutions or coding mistakes, but I have chosen to keep them as they are so that I can look back and see how much I have improved over time. As I learn new concepts, techniques, and best practices, I will continue to add new projects and update this repository. My hope is that, months or even years from now, I will be able to compare where I started with where I have ended up and appreciate the progress I made through persistence and continuous learning.
